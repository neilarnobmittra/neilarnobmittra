## 🚀 Featured Projects

### 🔐 QuantumShield AI

**AI-Powered Phishing Website & Brand Impersonation Detection System**

**Problem**

Phishing websites and brand impersonation attacks such as typosquatting can trick users into revealing sensitive information.

**Solution**

QuantumShield AI analyzes URLs, domains, metadata and website characteristics to calculate a security risk score and identify potentially malicious websites.

**Features**

* 🔎 Real-time phishing website detection
* 🛡️ Brand impersonation detection
* 🌐 Typosquatting detection
* 🧠 AI-based risk assessment
* 🔄 Self-learning feedback system
* ✅ Trusted domain whitelisting
* 📊 Security risk scoring dashboard
* 🚨 Report as Phishing / Report as Safe

**Tech Stack**

`Python` `Flask` `Scikit-learn` `JavaScript` `HTML` `Tailwind CSS` `JSON`

👉 [View Repository](https://github.com/neilarnobmittra/QuantumShield)
